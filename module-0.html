What GM0 Actually Is

Game Manual 0 (GM0) is a community-written FTC reference. It is not an official FIRST document, but it is the de facto handbook many veteran teams point rookies to.

GM0 is organized into ten big areas: Being a Team, Design Skills, Hardware Components, Custom Manufacturing, Common Mechanisms, Electronics, Software, Awards, Useful Resources, and an Appendix.

Team Building

Starting or Structuring a Team

StructureAdvantagesDisadvantages
School teamEasier to sustain, more consistent funding.Less schedule freedom, part-sourcing red tape, budget competition, often no summer practice.
Home teamFree practice schedule, no part restrictions.Harder sponsorships, space constraints.
Community teamMost flexible, best for donor tax write-offs.Hardest to set up, heaviest admin load.
Mentors

FIRST requires two mentors, both 18+, each passing Youth Protection Screening. Do not rely on one mentor; split technical mentorship from fundraising, leadership, outreach, and admin mentorship where possible.

Recruiting

Recruit from grade 7 upward so the team has a pipeline of returning members. Sustainability comes from new members learning before older members graduate.

India budget note: FTC India fees and kit purchasing should be checked against the current ftcindia.org.in season page before budgeting. The earlier reference figures were regional registration at Rs. 29,500 and National Championship registration at Rs. 39,500.

Organization Habits

Squads

Design, build/mechanical, software, outreach, drive team, and scouting.

Leadership

Squad leads who delegate well, optionally coordinated by one captain.

Cross-training

Programmers should understand CAD, builders should understand wiring, outreach should understand the robot.

Document onboarding: logins, software, build techniques, coding tools, and who is responsible for teaching each skill.

Know Your Lingo

Competition Terms

TermMeaning
PDPProgram Delivery Partner, the regional director for FTC events.
QualifierTournament with qualifying matches, alliance eliminations, judging, and advancement.
League MeetLower-stress ranked matches with no judging.
AllianceTwo teams during normal play; three in eliminations.
RP / TBPRanking Points are the main ranking metric. TieBreaker Points split into autonomous and endgame scoring.

Robot and Software Terms

DC Motor

Open-loop 12V motor. FTC robots may use up to 8.

Servo

Closed-loop PWM-controlled motor for precise positioning. FTC robots may use up to 12.

Drivetrain

The mechanism that moves the robot.

Intake

Picks up game elements using rotation or active contact.

Arm / Slide

Extends reach by rotation or linear motion.

DS / RC

Driver Station is with the drivers. Robot Controller rides on the robot.

Coding Track Decision

OptionBest forKey tradeoff
BlocksTrue beginners and fast onboarding.Good teaching tool, but not the best competitive end-state.
OnBot JavaStudents with some Java knowledge.Real Java in the browser, but external libraries are very limited.
Android StudioTeams wanting maximum flexibility.Steeper setup, but required for libraries like FTCLib, Road Runner, and FTC Dashboard.
Direct implication: Keep Blocks for onboarding brand-new members, but move experienced students toward OnBot Java or Android Studio if autonomous code, mecanum tuning, odometry, or dashboard-based debugging matter this season.

What To Study Next

High value for DECODE

Common Mechanisms, especially drivetrain, intake, linear slides, arms, and transfers.

High value for autonomous

Software concepts: LinearOpMode vs OpMode, telemetry, encoders, bulk reads, control loops, finite state machines, kinematics, and odometry.

Build quality

Hardware Components, Electronics, wiring guide, motor and servo selection, sensor glossary.

Judging

Awards, engineering portfolio, presentation, judging practice, and engineering notebook design.

5

Quick Action List

  • Confirm your team structure: school, home, or community.
  • Verify both required 18+ mentors have completed Youth Protection Screening.
  • Set up shared CAD and a GitHub repo, even if only one person codes right now.
  • Decide the programming track by sub-team: Blocks for recruits, OnBot Java or Android Studio for competitive code.
  • Draft a one-page onboarding doc covering logins, tools, and first skills to learn.
